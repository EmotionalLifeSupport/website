# Development Log Update Enforcement

Whenever you modify, add, or delete files in this repository (components, CSS, config, export scripts, or documentation):

1. Inspect `DEVELOPMENT_LOG.md`.
2. Append a new chronological entry under `## 📜 Chronological Change Log` using the established format:
   - Date & Title (`### [YYYY-MM-DD] — Description`)
   - Motivation / Root Cause
   - Key Changes
   - Files Modified
3. Keep line links accurate and ensure architectural notes remain up-to-date.
